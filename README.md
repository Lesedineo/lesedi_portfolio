# Personal Portfolio (Static HTML)

A lightweight, static personal portfolio built with plain HTML. This repository contains simple pages to showcase a brief biography, background, and education — ideal as a starter portfolio or quick personal site.

## Overview

This project includes a small set of static HTML files that together form a minimal personal portfolio site. It is intentionally simple so it's easy to host, edit, and extend.

## Files / Pages

- `Home.html` — Landing page with a short introduction and links to other pages.
- `About.html` — Personal background, summary of skills, and experience.
- `Education.html` — Academic history, certificates, and qualifications.

Open any file in a browser to view the site locally.

## Purpose

Use this repo as:

- A quick, zero-build portfolio to host on GitHub Pages or any static host.
- A starter template to learn HTML and experiment with styling and layout.

## How to view locally

Option A — Open directly:

1. Double-click any `.html` file in your file explorer.
2. The page will open in your default browser.

Option B — Run a simple local static server (recommended for linked assets):

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

## How to customize

- Replace the placeholder content with your own text and images.
- Add a `styles.css` file and link it from the HTML files to centralize styling.
- Add sections (Projects, Contact, Skills) as new HTML files or sections in existing pages.

## Deploying

- GitHub Pages: push the repository to GitHub and enable Pages from the repository settings (use the `main` branch or the `docs/` folder). The site will serve your static HTML directly.
- Any static host (Netlify, Vercel, Surge) works — just point the host to this repository or its build output.

## Suggestions for improvements

- Add a responsive layout and a central `styles.css`.
- Convert to a single-page layout or add a small JavaScript-based router.
- Add metadata (`<meta>` tags) for SEO and social sharing (Open Graph/Twitter card).
